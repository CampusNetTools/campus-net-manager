# 校园网连接管家 · 用户使用手册（v4.0.0）

> 界面形态（v4.0.0 起）：主界面为「总览 + 功能宫格」，每个功能点卡片即打开**独立窗口**——连接档案、隧道共享、网络控制台、热点分享、路由器检测、网络测速、偏好设置、网络报告、软件更新、运行日志等各占一个窗口，不再挤在主界面。

> Dr.COM 校园网自动保活 · 多设备共享上网 · macOS / Windows 桌面工具 + Android 手机版
> 项目主页：github.com/CampusNetTools/campus-net-manager

---

## 一、它解决什么问题

校园网（Dr.COM 等 Portal 认证）会**随机踢掉在线设备**，后台还显示在线。本软件：

- 自动检测掉线 → 用你的账号自动重登
- 在**非校园网环境自动休眠**，绝不乱登录
- 手机热点 / 路由器中继都可用，还能帮中继路由器保活
- 内置防踢保活：名额满时被挤掉的是别人，不是你
- 可以把网络分享给手机/平板（隧道共享），新设备需授权

## 二、快速上手（首次使用）

1. 打开 App → 首次会弹「新手向导」，跟着走 3 步即可
2. 或手动配置：主界面「连接档案」区
   - 档案下拉：选 **立达校园网 (LIDA-UNIVERSITY)**（内置档案，认证服务器已预填 `http://192.168.16.3/`）
   - 填你的 **账号**（学号）和 **密码**、选**运营商**（移动/联通/教师）
   - macOS 密码自动存入系统钥匙串，配置文件不存明文
3. 点「保存档案」→ 点 **「启动守护」**
4. 顶部状态看三个灯：
   - **守护**：运行中 / 已停止
   - **网络**：认证 + 外网是否都通
   - **环境**：校园网环境（工作）/ 非校园网（休眠）/ 任意网络

## 三、功能与使用方式

### 1. 连接档案（多网络自动匹配）

每个 WiFi/接入环境可以配一套档案（账号/密码/运营商/认证服务器），守护按规则自动选：

```
SSID 精确匹配（如 LIDA-UNIVERSITY）
  > 网关精确匹配（有线/路由器固定网关）
  > 你当前选中的档案（用户意图优先）
  > 默认兜底档案
```

| 操作 | 做法 |
|---|---|
| 新建档案 | 档案区「＋ 新建」→ 填名称 / 绑定 WiFi (SSID，可留空=默认) / 账号密码 / 运营商 / 认证服务器 → 保存 |
| 绑定方式 | 「无线」按 SSID 匹配；「有线」按网关 IP 匹配；SSID 和网关都留空的档案作为默认兜底 |
| 档案类型 | **校园网认证**＝登录保活；**普通WiFi·热点**＝不登录、只检测断网并通知（适合手机热点、家里 WiFi） |
| 家庭路由器场景 | 给档案绑定家里的 SSID 或网关，回家自动切到这个档案（类型选普通WiFi 就不会误登校园网） |
| 常用档案 | 顶部下拉切换即生效，守护下轮自动按新档案运行 |

### 2. 守护与自动重登（核心）

- **启动/停止守护**：主界面绿色大按钮；停止后 App 可继续浏览，但不再保活
- 运行周期：按档案的检测间隔（默认 10~60 秒，可在档案里调）
- 掉线自动重登；认证可达但出口不通会区分提示（链路断需重启路由器 / 账号名额满可去自助系统下线）
- **唤醒即检**：电脑睡眠唤醒、切换网络、自动登录成功后会立刻复检
- **守护自愈**：守护内部异常自动恢复，连续异常会记录并通知你
- 关闭窗口默认最小化到托盘，守护继续跑（点托盘图标恢复）

### 3. 开机自启 / 合盖保活

- **开机自启**：主界面「开机自启」按钮一键开关
- **合盖保活（macOS）**：偏好设置 →「合盖/休眠时保持运行」，合盖后仍自动联网保活

### 4. 防踢保活

校园网名额有限，超限会挤掉“最旧”会话。默认开启的防踢会周期性刷新你的登录会话，让你始终是“最新”的——第 3 台设备登录时被挤掉的是别人。偏好设置可关。

### 5. 隧道共享（多设备共享上网）

把你的电脑变成一个局域网网关/HTTP 代理，手机平板连上即可共享这条校园网：

1. 主界面点 **「隧道共享」** → 自动开启 HTTP 代理（默认 8080）
2. 窗口显示本机地址 + PAC + **二维码**，手机扫码自动配置（iOS 一键装描述文件 / 安卓鸿蒙一键填充）
3. **新设备首次连接需你授权**（防开放代理被滥用）；可设共享口令防蹭网
4. 可选 **VPN 上游**：填你本机 VPN 客户端代理端口（如 Clash 127.0.0.1:7890），接入设备流量自动走你的 VPN
5. 「🚀 一键部署」= 开启隧道 + 开机自启，常驻主力

适用形态：电脑直连校园网 → 分享；或电脑连中继路由器 → 手机连路由器 WiFi 即上网（软件帮你保路由器）。

### 6. 网络控制台（Web 管理页，手机也能用）

手机/电脑浏览器远程看这台电脑的管家状态：

1. 主界面点 **「网络控制台」**（端口 8081）→ 弹窗给地址和二维码
2. 手机浏览器打开（需连同一局域网）→ 看到：守护/网络/环境状态、最近日志、断网时间线、隧道已授权设备（可移除）、远程启动/停止守护
3. 访问需要弹窗里的口令（已含在链接中）

### 7. 热点设置（Windows 移动热点）

一键打开 Windows 移动热点设置页，电脑直连校园网时用系统热点带多设备。

### 8. 路由器检测 / 体检 / 中继指引

- **路由器检测**：自动识别品牌（华为/小米/TP-LINK/迅捷等），探测被改过的管理地址，一键打开管理页
- **只读体检**：读取网关/ARP/管理页标识/UPnP，评估刷机前置条件（只读，绝不登录改配置）
- **新手向导里的中继指引**：按你的路由器品牌分步教你设中继（方式 A 连校园网 / 方式 B 连主路由家 WiFi）
- **中继伪装检测**：扫描局域网可见设备，评估“多设备共享”暴露风险并给轻量建议（改 TTL/关 WPS/隐藏 SSID）
- 刷机必须：先确认精确型号+官方适配镜像+SHA256+配置备份，仍要人工确认

### 9. 网络质量与诊断

- **网络测速**：限流测速不伤套餐；给延迟（TCP/TLS 校正）、抖动、成功率、质量评分；自动识别 VPN 并对比“走 VPN”与“直连”
- **导出诊断**：一键生成脱敏诊断报告（日志+状态），发给开发者排查
- **认证服务器探测**：多来源探测认证页（支持同时发现多个认证服务器加入下拉框）
- 日志面板实时滚动；自动轮转清理，不会无限增长

### 10. 偏好设置与网络报告

- 打开：主界面底部「偏好设置与网络报告」
- 内容：
  - 保存**网络稳定性历史**（默认关；开启后只记连接状态，7 天报告 + 断网时间线，提示路由器散热/链路规律）
  - 合盖保持运行 / 防踢 / **启动时自动检查新版本** 开关
  - **系统通知分类**：允许通知总开关 + 掉线/恢复/恢复失败/新设备请求 4 类子开关
  - 测试通知按钮
  - **软件更新**面板：显示当前版本 + 检查更新按钮 + 内联结果；发现新版点「立即更新」自动下载替换

### 11. 自动更新

- 启动时自动联网检查 GitHub 新版本（可在偏好关闭；发现新版本弹窗提示，也可跳过一个版本）
- 点击「立即更新」→ 下载 → 应用退出 → 自动替换 → 重新打开（macOS / Windows 都支持）
- 检查依赖系统 HTTPS 证书，已内置证书包，无需额外配置

### 12. 安全与隐私

- 密码仅存 **macOS 钥匙串 / Windows 凭据管理器**，配置文件与“导出配置”不含明文密码
- 网络历史默认关闭；开启只记录“连接/断网”状态，不记录上网内容
- 诊断导出自动脱敏
- 隧道共享有口令 + 新设备授权，不是开放代理

## 四、常见使用场景速查

| 场景 | 怎么做 |
|---|---|
| 在校（连 LIDA-UNIVERSITY） | 用「立达校园网」档案，启动守护即可 |
| 寝室有路由器中继校园网 | 电脑连中继 WiFi；给中继的 SSID 建档案（校园网类型）或绑网关；软件自动帮路由器保活 |
| 在家里 WiFi / 手机热点 | 建“普通WiFi”类型档案并绑定该 SSID；只检测断网通知，绝不误登校园网 |
| 想分享给手机 | 隧道共享 → 扫码（推荐选：电脑连校园网、手机连电脑热点/中继 WiFi） |
| 想手机远程看电脑状态 | 网络控制台 → 手机浏览器打开地址 |
| 网络老掉线 | 打开偏好里的网络历史 + 看 7 天报告/断网时间线找规律 |
| 想更新软件 | 偏好设置 → 软件更新 → 检查更新 → 立即更新 |

## 五、平台差异

| | macOS | Windows |
|---|---|---|
| 安装 | 解压 .app 拖入 Applications（未公证需右键→打开一次） | 单文件 exe 双击即用 |
| 密码存储 | 系统钥匙串 | 配置目录 |
| 合盖保活 | caffeinate 电源断言，支持 | 电源计划控制，支持有限 |
| 开机自启 | LaunchAgent | 注册表 |

## 六、文件位置（默认）

- 配置文件：`~/Library/Application Support/CampusNetManager/config.json`（macOS）；exe 同目录 `config.json`（Windows）
- 运行日志：同目录 `keepalive.log`（自动清理，最大约 2MB）
- 网络历史：同目录 `network_history.jsonl`（仅当你开启网络历史后产生）

## 七、手机版（Android，可选）

`mobile/` 目录独立 Android App（Kivy），复用同一套 Dr.COM 登录核心：

- 手机直连校园网 WiFi 时：填账号密码 →「立即登录」→「开启保活」（前台每 60 秒检测，掉线自动重登）
- APK：GitHub Actions「手机版 APK」手动触发构建，debug 包可直接安装
- 限制：后台保活依赖系统调度（建议关闭该 App 的电池优化）；iOS 暂不支持
