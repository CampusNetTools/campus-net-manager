# Windows 实机验收交接

目标：请在真实 Windows 电脑上验收免费直下载版 v5.6.0。此文档供另一台设备上的 AI 按步骤执行并记录证据；不代表本机已完成 Windows 验收。

## 下载与文件核验

- 正式直下载页：<https://github.com/CampusNetTools/campus-net-manager/releases/tag/v5.6.0>
- 主程序：`CampusNetManager-v5.6.0-win64.exe`
- SHA-256 sidecar：`CampusNetManager-v5.6.0-win64.exe.sha256`
- Release API 提供的主 EXE SHA-256：`a0faeff9ea197e7e34be582059fdfc64d97679e6cfac265010c3bc9df337c689`
- PowerShell 核验：`(Get-FileHash .\CampusNetManager-v5.6.0-win64.exe -Algorithm SHA256).Hash.ToLower()`，结果必须与上述值和 sidecar 一致。
- 该 EXE 未做 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。哈希不匹配时停止，不运行；匹配只证明文件完整性，不证明签名或安全扫描通过。

## 安全测试准备

1. 复制 EXE 到独立测试目录，以普通 Windows 用户运行，不要覆盖已有版本或真实的 `config.json`、日志。
2. 不输入校园网账号、密码、路由器口令、VPN 订阅、令牌或验证码。不要把凭据、完整日志、个人路径、设备序列号或含个人信息的截图回传。
3. 如果出现防火墙提示，先取消或拒绝 Public network。确需验证局域网功能时，先让用户决定是否仅允许 Private network。
4. 不启动守护登录、热点、隧道代理、网络控制台、开机自启、配置导入/覆盖或自动更新等会改变网络、启动项或本机数据的功能；未获用户授权前只打开页面和做只读观察。

## 验收步骤

- [ ] 下载完成；EXE SHA-256 与 sidecar/Release 值相符。
- [ ] 普通用户启动；记录 Windows 版本、EXE 版本、首次启动错误或 SmartScreen 表现（不上传设备唯一标识）。
- [ ] 主窗口显示正常，中文可读；检查状态区域、功能卡片、托盘图标/菜单和关闭窗口后的行为。只打开页面，不启动具有副作用的操作。
- [ ] 打开连接档案、日志、网络报告、路由器只读体检、网络测速、新手向导、偏好设置、更新页面；检查可打开、返回/关闭、中文显示和明显报错。测速会产生网络流量，可跳过或先获用户同意。
- [ ] 使用只读/脱敏诊断导出检查日志和配置导出不含密码、令牌或订阅内容；不要把原始文件上传。可只反馈“通过/失败”和脱敏错误类型。
